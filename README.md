# 📚 Прохождение уровней Natas

### 🔹 Level 1 ➔ Level 2

- **Цель:** Найти пароль на странице, где заблокирован клик правой кнопкой мыши.
- **Теория:** Запрет контекстного меню на стороне клиента — это простая обманка. Браузер в любом случае загружает исходный код для отображения страницы.
- **Решение:** Обойдите блокировку мыши, нажав клавиши `Ctrl + U` на клавиатуре для просмотра исходного кода страницы.
- **Пароль скрыт в строке:** `<!-- The password for natas2 is [ПАРОЛЬ] -->`

### 🔹 Level 2 ➔ Level 3

- **Цель:** Найти скрытый файл с учетными данными на сервере.
- **Теория:** Если на сервере не отключено отображение содержимого папок (Directory Indexing), можно вручную перейти по пути к открытой директории и посмотреть все файлы.
- **Решение:** 
  1. Откройте исходный код страницы. Там присутствует тег картинки: `<img src="files/pixel.png">`.
  2. Удалите имя картинки из адресной строки и перейдите в саму папку `/files/`.
  3. Откройте находящийся там текстовый файл `users.txt`.
- **Содержимое файла:** Строка вида `natas3: [ПАРОЛЬ]`

### 🔹 Level 3 ➔ Level 4

- **Цель:** Найти секретный файл, который скрыт от поисковых роботов.
- **Теория:** Файл `robots.txt` указывает поисковикам, какие страницы не нужно индексировать. Веб-исследователи всегда проверяют его в первую очередь, так как там часто записаны пути к скрытым каталогам.
- **Решение:** 
  1. Перейдите по адресу `/robots.txt`. Там будет запись: `Disallow: /s3cr3t/`.
  2. Перейдите в эту скрытую директорию `/s3cr3t/`.
  3. Откройте текстовый файл `users.txt`.
- **Содержимое файла:** Строка вида `natas4: [ПАРОЛЬ]`

### 🔹 Level 4 ➔ Level 5

- **Цель:** Получить доступ к странице, подменив источник перехода (Referer).
- **Теория:** HTTP-заголовок `Referer` указывает серверу адрес страницы, с которой пришел пользователь. Сервер доверяет только запросам, пришедшим с предыдущего уровня (natas5). Этот заголовок отправляется клиентом, поэтому его можно изменить вручную.
- **Решение:** Используйте плагин для модификации заголовков (например, *Header Editor*) или утилиту `curl` в терминале, чтобы отправить запрос с поддельным заголовком.
- **Команда:** `curl -u natas4:[ТЕКУЩИЙ_ПАРОЛЬ] -H "Referer: http://overthewire.org" http://overthewire.org`

### 🔹 Level 5 ➔ Level 6

- **Цель:** Войти в систему, изменив значение в файлах Cookie.
- **Теория:** Cookies (куки) используются для сохранения состояния сессии. Если приложение принимает решение об авторизации пользователя только на основании переменной в куках (например, `loggedin=0`), ее можно вручную изменить на `1`.
- **Решение:** 
  1. Откройте инструменты разработчика (клавиша `F12`).
  2. Перейдите во вкладку **Application** (в Chrome) или **Storage** (в Firefox), затем выберите пункт **Cookies**.
  3. Найдите куку с именем `showpassword`, измените ее значение с `0` на `1` и обновите страницу (`F5`).
- **Результат:** После обновления страницы отобразится пароль для `natas6`.
